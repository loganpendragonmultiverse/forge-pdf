# Contributing

Install `.[dev]` in a virtual environment. Run pytest, Ruff checks and formatting,
then build the package. For UI changes, exercise the actual desktop window at its
default and minimum sizes. Test saved files by reopening them, not only by inspecting bytes.

Use synthetic, redistributable fixtures. Never submit client PDFs, credentials, or personal
documents. Whiteout must never be described as secure deletion. Preserve original files,
transactional edits, license notices, and the no-network runtime boundary.

Submit changes through a pull request with the relevant tests and documentation.
The maintainer reviews correctness, PDF fidelity, security, scope, and licensing before merge.
